WAYGOOD — Site web de restaurant
Présentation du projet
WAYGOOD est un site web de restaurant développé en 2025 avec HTML, CSS et Bootstrap. Il a pour objectif de présenter le restaurant, de mettre en valeur son univers culinaire et de faciliter la navigation des visiteurs grâce à une interface moderne et élégante.
Fonctionnalités
• Page d’accueil avec une présentation visuelle du restaurant.
• Barre de navigation pour accéder aux différentes sections du site.
• Présentation du restaurant et de son univers.
• Section dédiée au menu.
• Accès aux informations de contact et aux services proposés.
• Interface adaptée à une expérience de navigation agréable.
Technologies utilisées
• HTML5 : structure des pages web.
• CSS3 : mise en forme et personnalisation du design.
• Bootstrap : création d’une interface structurée et responsive.
Installation et utilisation
1. Clonez ou téléchargez le dépôt GitHub.
2. Ouvrez le dossier du projet.
3. Lancez le fichier index.html dans votre navigateur.
Aucun serveur n’est nécessaire pour consulter les pages statiques du site, sauf si le projet utilise des fonctionnalités supplémentaires qui l’exigent.
Objectifs du projet
• Mettre en pratique les compétences en développement web.
• Concevoir une interface utilisateur claire et esthétique.
• Utiliser Bootstrap pour accélérer la création de l’interface.
• Développer un site vitrine destiné au secteur de la restauration.
